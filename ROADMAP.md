# Omalook roadmap

## Done
- Multi-account (Microsoft 365 via Graph, Gmail via Google APIs) with per-user OAuth clients
- Tokens in the system keyring (file fallback)
- Mail: folders (nested / labels), paging, search, read / flag / archive / junk / delete
- Compose: rich text, attachments, drafts, reply / reply all / forward, contact autocomplete
- Attachment download, inline `cid:` images, remote-image blocking
- Calendar (day / week / month, multi-account) and contacts (CRUD)
- Omarchy theme sync, in-app setup guides

## Ideas
- Desktop notifications for new mail
- Conversation / thread view
- Per-account signatures
- Meeting invitation RSVP
- Offline cache and faster search
- Outlook-style rules
- Packaging (AUR, AppImage) and an app icon
